# Uber EDA [Learning Project] [Personal Repository]

This repository contains a personal learning project focused on Exploratory Data Analysis (EDA) using Python and Jupyter Notebook.

The project was created mainly for learning purposes by following tutorials, experimenting with code, and using AI-assisted guidance to better understand the EDA workflow, data visualization techniques, and ride-booking patterns.

## Objectives

* Practice data cleaning and preprocessing
* Analyze Uber ride booking patterns
* Explore ride categories, purposes, and trip distances
* Visualize trends using graphs and charts
* Understand basic EDA techniques using Python

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Key Insights

* Business rides were significantly more common than personal rides
* "NOT SPECIFIED" was the most common ride purpose, while Meeting was the most frequent specified purpose
* Most Uber rides were booked during the Afternoon
* April recorded the highest number of bookings, while July had the lowest
* Friday was the busiest day for Uber ride bookings
* Most trips were short-distance rides between 0 and 10 miles

## Note

This is a beginner-friendly learning project created to document my progress in data analysis and improve my understanding of Exploratory Data Analysis (EDA) concepts. The project focuses on extracting insights from Uber ride data through data cleaning, visualization, and interpretation.
